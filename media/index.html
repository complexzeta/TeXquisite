Build settings
  
Tools, packages and fast preview
TeXquisite uses your installed TeX files. Windows with TeX Live is the supported initial setup; MiKTeX native compilation is experimental. Missing packages must be installed with your TeX distribution’s package manager.
Edits are submitted to the preview immediately and saved automatically. A save conflict preserves your draft while the preview continues to compile it. Pause Live to edit without saving.
Compilation uses a 120-second timeout. Shell escape and latexmk configuration files are disabled in this prototype.
Unused compiler caches expire after seven days or when they exceed 512 MB where safe. Active projects and preview navigation are retained.
Sources, drafts and accepted previews are kept.


Source backups
Changed open source files are backed up every five minutes, when opened, and when closing. This includes unsaved drafts while Live is paused.
Keep 20 recent snapshots per document, plus hourly copies for a day and daily copies for two weeks, within 200 snapshots and 128 MB total. Images and other project assets are not included. Backups are stored locally in the app profile.


Find and replace in project
Search uses open drafts. Regex replacements support $1, $<name>, $& and $$. Review and select changes below before replacing. Undo works separately in each changed file.
