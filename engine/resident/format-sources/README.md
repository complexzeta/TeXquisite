# Fingerprinted format inputs

These kernel/configuration files retain their original copyright and license notices. The generated first-line installation comment in language.dat has been removed for privacy; its executable configuration entries and public-domain notice are unchanged. This comment has no effect on TeX execution.

format.json records compatibility fingerprints of the installed inputs used for the bundled format. The language.dat policy excludes its generated first-line comment and normalizes CRLF; this redacted copy therefore retains the same compatibility fingerprint. Other inputs retain exact-byte hashes. The runtime checks the selected installation against those recorded fingerprints. Rebuilding the format uses the installed TeX resources as documented in ../SOURCE-BUILD.md; do not bypass compatibility checks.
